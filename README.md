mierp
----

mierp is a suite of web based open source business apps.

The main mierp Apps include an <a href="127.0.0.1:8730/page/crm">Open Source CRM</a>,
<a href="127.0.0.1:8730/app/website">Website Builder</a>,
<a href="127.0.0.1:8730/app/ecommerce">eCommerce</a>,
<a href="127.0.0.1:8730/app/inventory">Warehouse Management</a>,
<a href="127.0.0.1:8730/app/project">Project Management</a>,
<a href="127.0.0.1:8730/app/accounting">Billing &amp; Accounting</a>,
<a href="127.0.0.1:8730/app/point-of-sale-shop">Point of Sale</a>,
<a href="127.0.0.1:8730/app/employees">Human Resources</a>,
<a href="127.0.0.1:8730/app/social-marketing">Marketing</a>,
<a href="127.0.0.1:8730/app/manufacturing">Manufacturing</a>,
<a href="127.0.0.1:8730/">...</a>

mierp Apps can be used as stand-alone applications, but they also integrate seamlessly so you get
a full-featured <a href="127.0.0.1:8730">Open Source ERP</a> when you install several Apps.

Getting started with mierp
-------------------------

For a standard installation please follow the <a href="127.0.0.1:8730/documentation/master/administration/install/install.html">Setup instructions</a>
from the documentation.

To learn the software, we recommend the <a href="127.0.0.1:8730/slides">mierp eLearning</a>, or <a href="127.0.0.1:8730/page/scale-up-business-game">Scale-up</a>, the <a href="127.0.0.1:8730/page/scale-up-business-game">business game</a>. Developers can start with <a href="127.0.0.1:8730/documentation/master/developer/howtos.html">the developer tutorials</a>
